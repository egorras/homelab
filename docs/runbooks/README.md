- [reinstall-proxmox.md](reinstall-proxmox.md): wipe and reinstall the Proxmox host from USB
- [ci-access.md](ci-access.md): tailnet policy, CI OAuth client, GitHub secrets, tofu state passphrase
- [migrate-previous-lab.md](migrate-previous-lab.md): one-time carry-over of HA, Jellyfin, AdGuard state from the old lab
- [monitoring.md](monitoring.md): phone alerts via Telegram, Grafana login, adding probes
- [new-app.md](new-app.md): add an app from kubernetes/apps/_template in one PR
- [headlamp.md](headlamp.md): Kubernetes web UI (Headlamp) and Lens/kubectl access
- [immich.md](immich.md): Immich storage layout, database restore from a dump, upgrades
